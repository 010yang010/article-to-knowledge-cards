# make-knowledge-cards

一个可开源的 AI 技能（兼容 WorkBuddy 与 OpenAI Agent Skills 标准），把用户**粘贴的文章**或**本地 Markdown / TXT 文件**提炼成一组结构化的知识卡片，方便复习与记忆。

## 介绍

- 输出 **5～8 张**知识卡片（原文要点较少时自动少于 5 张，绝不强行凑数）。
- 每张卡片固定包含四部分：**标题、核心知识、简明解释、例子或自测问题**。
- 严格遵守质量约束：只提取真正重要的知识、一张卡片只讲一个知识点、删除重复内容、**绝不编造原文没有的信息**、信息不足时不凑数量。
- 输入来源：直接粘贴文本，或提供本地 `.md` / `.txt` 文件路径。
- 明确**不支持**：网页抓取、PDF 解析、Anki 牌组导出、图形界面。

## 使用方法

1. **粘贴文本**：把文章/笔记直接发到对话，并说“帮我做成知识卡片”。
2. **本地文件**：给出 `.md` 或 `.txt` 文件的完整路径，例如“读取 `F:/docs/article.md` 并生成知识卡片”。
3. **保存到文件**（可选）：若需要，可要求“把卡片保存为 `cards.md`”，技能会写入一个 Markdown 文件；默认仅在对话中呈现。

> 若你提供的是 PDF、网页链接或图片，技能会明确告知“暂不支持”，并建议你把正文复制为文本后粘贴。

## 输入示例

```
数据库索引是一种帮助数据库快速查找数据的结构，最常见的是 B+ 树索引。
没有索引时，数据库只能做全表扫描，逐行比对，数据量越大越慢。
有了索引，可以像查字典目录一样快速定位，把查找从 O(n) 降到接近 O(log n)。
索引不是免费的：它占用额外空间，并在增删改时需要维护，降低写入性能。
常见误区是把所有列都加上索引——索引过多会浪费空间、拖慢写操作。
```

## 输出示例

```
### 卡片 1：索引是什么——数据的“字典目录”
- **核心知识**：数据库索引是一种加速查找的数据结构，最常见的是 B+ 树索引。
- **简明解释**：它像书的目录，让数据库不必逐页翻找就能直接跳到目标位置。
- **例子 / 自测问题**：没有目录时，如何在一本 1000 页的书里找关键词？这与全表扫描有何关系？

### 卡片 2：索引把查找从 O(n) 降到约 O(log n)
- **核心知识**：无索引时需全表扫描（O(n)），有索引后可快速定位（约 O(log n)）。
- **简明解释**：数据量越大，有无索引的差距越悬殊。
- **例子 / 自测问题**：数据量从 1 万行涨到 1 亿行，二者差距大约扩大多少倍？
```
