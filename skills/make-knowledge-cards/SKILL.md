# Make Knowledge Cards（知识卡片生成）

## Overview

把一段较长的文本（用户直接粘贴的文章，或本地 Markdown / TXT 文件）提炼成一组结构化的知识卡片，帮助用户快速抓住重点、便于复习。每张卡片只承载一个知识点，输出严格忠实于原文。

## When to Use

在以下场景触发本技能：

- 用户粘贴了一篇文章、博客、学习笔记、文档片段，并希望“总结成卡片 / 做成知识点 / 提炼重点 / 帮我复习”。
- 用户提供了本地 `.md` 或 `.txt` 文件路径，要求从中生成知识卡片。
- 用户表达出把内容拆成“一张一张可复习的要点”的意图。

不要在本技能范围内处理：网页 URL（不抓取）、PDF（不解析）、图片中的文字、以及任何要求导出到 Anki 或图形界面的请求。遇到这些请求，明确告知不支持，并提议改用本地文本粘贴。

## Input Handling（输入处理）

先确认输入来源，再开始处理：

1. **粘贴文本**：用户已在对话中给出正文，直接基于该文本处理，无需读取文件。
2. **文件路径**：用户给出文件位置时，使用 Read 工具读取 `.md` / `.txt` 内容。若用户只说了文件名而未给路径，先向用户确认完整路径，不要猜测。
3. **格式边界**：仅接受纯文本、Markdown、TXT。若用户提供 PDF / 网页链接 / 图片，明确回复“暂不支持”，并建议其把正文复制为文本后再粘贴。

## Card Format（卡片格式）

每张卡片固定包含四个部分，按顺序输出：

```
### 卡片 N：<标题>
- **核心知识**：用一句话点明这一张卡片要记住的关键结论。
- **简明解释**：用 2～4 句通俗语言解释它是什么、为什么重要，必须忠于原文。
- **例子 / 自测问题**：给出（a）一个具体例子，或（b）一道可自检是否理解的小问题。二选一即可，不要同时省略。
```

- **标题**：简短、可独立成意，能让人一眼知道这张卡片讲什么（如“边际效用递减”“HTTP 与 HTTPS 的区别”）。
- **核心知识**：是这张卡片的“一句话结论”，避免在此展开。
- **简明解释**：面向复习者，类比、对比、因果都可用，但不得引入原文没有的事实。
- **例子 / 自测问题**：优先用原文中的素材；原文无合适素材时，可基于原文概念构造一个最小化的自测问题（问题本身不引入新事实）。

## Quality Rules（质量规则，必须严格遵守）

1. **只提取真正重要的知识**：优先保留原文的核心概念、关键结论、易混淆的对比、作者强调的要点；省略举例性闲笔、客套话、与主旨无关的铺陈。
2. **一张卡片只讲一个知识点**：不要把两个独立概念塞进同一张卡。若一个段落包含多个要点，拆成多张卡片。
3. **删除重复内容**：通读时合并表达相同或高度相似的观点，不因为原文重复出现就重复成卡。
4. **绝不编造原文没有的信息**：每一张卡片里的每一条陈述都必须能在原文中找到依据。推断、补充背景、润色可以，但不得添加原文未提及的事实、数据、人名、年份或结论。无法确认的内容，宁可省略。即便在“例子 / 自测问题”中，也不得编造具体的时间、数字、人名、年份或事件；若必须用假设性例子帮助理解，须明显标注其为“假设”，且不暗示这是原文陈述的事实。
5. **信息不足时不强行凑数量**：卡片目标数量为 5～8 张，但这是“上限与目标区间”，不是硬性配额。当原文本身只含 2～4 个真正独立的重要点时，只产出那么多，并在开头用一句话说明“原文要点较少，共生成 N 张”。反之，若原文极长且要点很多，以 8 张为软上限，挑选最重要的产出，不要无限堆叠。
6. **保留原文术语与立场**：术语、专有名词、数据口径沿用原文；不擅自改变作者的观点倾向或结论。

## Workflow（工作流程）

1. **确认输入**：按“Input Handling”判断是粘贴文本还是文件路径，必要时询问路径。
2. **通读标注**：完整读完原文，用内部笔记标出候选知识点，并标注每点的重要性与所在位置（便于溯源）。
3. **去重与排序**：合并重复观点；按“重要性 + 独立性”排序，确定最终卡片清单与数量（遵循质量规则第 5 条）。
4. **逐张生成**：按“Card Format”为每张卡片产出标题、核心知识、简明解释、例子或自测问题，时刻对照质量规则第 4 条（不编造）。
5. **自检**：生成后逐张核对——
   - 是否每张只讲一个知识点？（规则 2）
   - 是否有重复？（规则 3）
   - 每条陈述是否都能在原文找到依据？（规则 4）
   - 数量是否忠实于原文信息量？（规则 5）
   发现问题的卡片直接修正或删除。
6. **输出**：在对话中以 Markdown 输出全部卡片；若用户要求保存，可写入一个 `.md` 文件（文件名与原文相关），否则默认仅对话内呈现。

## Limitations（明确不支持）

- 网页抓取（不访问 URL 抓取内容）
- PDF 解析（不接受 PDF 作为输入）
- Anki 或任何间隔重复软件的牌组导出
- 图形界面 / 可视化卡片排版
- 翻译、改写全文、扩写等超出“提炼成卡片”范围的任务（可建议用户改用其他技能）

## Example（简短示例）

输入（用户粘贴）：

> 光合作用分为光反应和暗反应。光反应在类囊体膜上进行，把光能转为 ATP 和 NADPH；暗反应在基质中进行，利用这两种物质把 CO₂ 固定成糖。光照强弱主要影响光反应，而温度主要影响暗反应中的酶活。

输出：

### 卡片 1：光合作用的两大阶段
- **核心知识**：光合作用由光反应和暗反应两个阶段组成。
- **简明解释**：二者分工不同但相互衔接，光反应制造能量载体，暗反应用这些能量合成有机物。
- **例子 / 自测问题**：能否分别说出光反应和暗反应“在哪里进行、产出什么”？

### 卡片 2：光反应
- **核心知识**：光反应在类囊体膜上把光能转化为 ATP 和 NADPH。
- **简明解释**：这是能量捕获环节，依赖光照，产物供暗反应使用。
- **例子 / 自测问题**：为什么“光照变弱”会首先影响光反应而不是暗反应？

### 卡片 3：暗反应
- **核心知识**：暗反应在基质中利用 ATP 和 NADPH 把 CO₂ 固定成糖。
- **简明解释**：这是碳同化环节，不直接依赖光，但依赖光反应提供的能量物质。
- **例子 / 自测问题**：若突然中断 ATP 供应，暗反应会如何变化？

### 卡片 4：光照与温度的不同影响
- **核心知识**：光照强弱主要影响光反应，温度主要通过影响酶活性作用于暗反应。
- **简明解释**：这是两个环境因子作用位点的区别，有助于解释“为什么阴天和低温对光合的影响路径不同”。
- **例子 / 自测问题**：低温天的中午光照充足，此时限制光合的主要环节更可能是哪一个？
